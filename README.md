# 💻 Archivo de Ejercicios en C++

¡Hola! Bienvenido a mi repositorio histórico de C++.

Este proyecto contiene una colección de **70 archivos prácticos** que desarrollé durante mis primeros semestres en la universidad.
## 🗂️ Estructura del Repositorio
El código está dividido en dos etapas principales que reflejan mi progreso:

### 📂 01_Fundamentos (27 Archivos: 25 Ejercicios y 2 Proyectos)
Aquí se encuentran mis primeras prácticas aprendiendo a programar.
* **Temas aplicados:** Lógica básica, condicionales (`if`, `switch`), ciclos (`for`, `while`), y manejo de vectores y matrices.

### 📂 02_Profundizacion (43 Archivos: 42 Ejercicios y 1 Proyecto)
En esta etapa di el salto a la programación estructurada y modular, aplicando conceptos de mayor complejidad técnica.
* **Temas aplicados:** Funciones, punteros, paso de parámetros por referencia, cadenas, recursividad, vectores dinámicos, estructuras (`structs`), y lectura/escritura de archivos de texto y binarios.

## 🛠️ Herramientas Utilizadas
* **Lenguaje:** C++
* **Entorno de Desarrollo (IDE):** Dev-C++
